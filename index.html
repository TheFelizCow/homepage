Sync as Chrome Homepage & New Tab

To have this page open automatically on **all your devices running Chrome** whenever you open the browser or a new tab:

Option 1: Chrome Extension "Custom New Tab URL" (Recommended)

  1. Install a lightweight Chrome extension like "New Tab Redirect" or "Custom New Tab URL" from the Chrome Web Store.
  2. In the extension settings, set the Redirect URL to your LXC container address (or Tailscale / Cloudflare tunnel domain if on mobile/laptop away from home).
  3. Turn on Chrome Profile Sync so extensions automatically sync across all your desktop computers.

Option 2: Native Chrome Startup Page (No Extension)

  1. Go to Chrome Settings → On startup → Open a specific page.
  2. Add the URL of your LXC container.
